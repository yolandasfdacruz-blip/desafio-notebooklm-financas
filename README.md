# Desafio NotebookLM: Organização Financeira Pessoal

Projeto desenvolvido durante o curso Santander 2026 da DIO.

## Objetivo

Criar um caderno temático no NotebookLM para estudar conceitos
introdutórios de organização financeira pessoal, utilizando fontes
abertas, perguntas estratégicas e prompts reutilizáveis.

## Tema

Organização financeira pessoal para iniciantes.

## Ferramentas utilizadas

- NotebookLM
- GitHub
- Markdown

## Conteúdos do projeto

- [Miniguia de Organização Financeira](miniguia-organizacao-financeira.md)
- [Fontes Consultadas](fontes-consultadas.md)
- [Prompts Reutilizáveis](prompts-reutilizaveis.md)

## Etapas realizadas

- Curadoria de três fontes institucionais.
- Criação de um caderno temático no NotebookLM.
- Definição dos objetivos de estudo.
- Elaboração de perguntas estratégicas.
- Registro das respostas e referências.
- Criação de um glossário.
- Elaboração de prompts reutilizáveis.
- Organização do conteúdo em um miniguia.

## Aprendizados

Durante o projeto, aprendi a utilizar o NotebookLM para organizar fontes,
formular perguntas, estudar um tema com apoio de inteligência artificial
e transformar informações em um material de revisão estruturado.

Também aprendi a publicar e organizar documentos em um repositório do
GitHub utilizando o formato Markdown.
