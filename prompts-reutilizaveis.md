# Prompts Reutilizáveis para Estudo

Os prompts abaixo foram elaborados para apoiar futuras sessões de
estudo no NotebookLM.

## 1. Resumir um assunto

### Objetivo

Obter um resumo claro e organizado sobre determinado assunto.

### Prompt

Com base exclusivamente nas fontes adicionadas a este caderno, faça um
resumo objetivo e bem estruturado sobre [inserir assunto]. Destaque as
ideias centrais e indique as fontes utilizadas.

## 2. Explicar um conceito difícil

### Objetivo

Compreender um conceito usando linguagem simples.

### Prompt

Explique o conceito de [inserir conceito] utilizando exclusivamente as
fontes deste caderno. Traduza a explicação para uma linguagem simples,
apresente um exemplo prático e indique as fontes consultadas.

## 3. Criar um exemplo prático

### Objetivo

Relacionar o conteúdo estudado com uma situação cotidiana.

### Prompt

Com base exclusivamente nas fontes adicionadas, crie um cenário prático
que ilustre a aplicação de [inserir conceito] na rotina de uma pessoa
iniciante. Explique o que pode ser aprendido com esse exemplo.

## 4. Comparar dois conceitos

### Objetivo

Identificar semelhanças e diferenças entre conceitos.

### Prompt

Utilizando exclusivamente as fontes deste caderno, compare [Conceito A]
e [Conceito B]. Apresente as definições, as principais diferenças e um
exemplo de aplicação de cada conceito.

## 5. Criar perguntas para revisão

### Objetivo

Revisar o conteúdo e verificar a compreensão.

### Prompt

Com base exclusivamente nas fontes deste caderno sobre [inserir tema],
crie cinco perguntas de revisão e um gabarito comentado, fundamentado
diretamente nas fontes.

## 6. Identificar informações importantes

### Objetivo

Encontrar alertas, erros comuns e pontos essenciais nas fontes.

### Prompt

Analise as fontes deste caderno e liste os cinco principais alertas ou
erros que uma pessoa iniciante deve evitar sobre [inserir tema].
Explique o motivo de cada ponto e indique as fontes correspondentes.

## Observação

Os campos entre colchetes devem ser substituídos pelo assunto ou
conceito que será estudado. É importante solicitar ao NotebookLM que
utilize exclusivamente as fontes adicionadas e informe as referências.
